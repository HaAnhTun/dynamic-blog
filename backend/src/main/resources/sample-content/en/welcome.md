## What you are reading

This is a **sample post**. It was created by the "Load sample content" button in the admin settings so that a new site
does not look empty. Nothing here is tied to a real person, and you can edit or delete every item.

## What you can do next

- Open the admin settings and fill in your own profile, about page, contact links and blogroll. The text of the public
  pages comes from there, one version per language.
- Use the profile import to fill several sections at once from one Markdown file. The import shows a preview first and
  can be undone.
- Write a post in one language, then create its translation. The two posts are linked, so readers can switch language.
- Publish when you are ready. Readers who subscribed to the newsletter receive new posts in their own language.

## Where things live

| Part of the site | Where you change it |
|---|---|
| Name, tagline, profile, about, contact | Admin settings, per language |
| Posts, categories, tags, series | The admin area |
| Newsletter subscribers and issues | The newsletter page of the admin area |

> A sample item is an ordinary item. Once it exists, you manage it like anything you wrote yourself.

## Removing the samples

Delete the four sample posts, the "Getting started" series, the "Guides" category and the two tags from the admin area.
Loading the samples again later creates only what is missing.
