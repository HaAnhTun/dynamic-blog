# Bảng thuật ngữ giao diện (vi ↔ en)

Mỗi khái niệm dùng đúng một từ trong mỗi ngôn ngữ, ở mọi màn hình, `aria-label`, thông báo lỗi và tài liệu. Chữ hiển thị nằm ở
`frontend/messages/vi.json` và `frontend/messages/en.json`; khi thêm hoặc sửa một chuỗi, dùng từ trong bảng này.
English summary: one term per concept in each language; the English column is the term to use in `en.json`, in comments
and test titles that quote the interface, and in the README.

| Khái niệm | Tiếng Việt | English |
|---|---|---|
| Bài đăng | bài viết, bài | post |
| Loạt bài | series | series |
| Chủ đề | chủ đề | topic |
| Chuyên mục | chuyên mục | category |
| Thẻ | thẻ | tag |
| Tác giả, độc giả, chủ site | tác giả, độc giả (người đọc), chủ site | author, reader, site owner |
| Quản trị | quản trị, Quản trị | admin |
| Bình luận, trả lời | bình luận, trả lời | comment, reply |
| Thích | thích, lượt thích | like, likes |
| Lưu bài | lưu bài, bài đã lưu | save, saved posts |
| Nhận bài qua email | nhận bài qua email, đăng ký | newsletter, subscribe |
| Trạng thái bài | bản nháp, đã đăng | draft, published |
| Đăng, gỡ | đăng, gỡ | publish, unpublish |
| Lưu trữ | lưu trữ | archive |
| Ảnh | ảnh | gallery, photo |

Văn phong tiếng Anh: câu ngắn, viết hoa kiểu câu cho nhãn và tiêu đề ("Sign in", không phải "Sign In"), nút dùng động từ mệnh
lệnh, chủ site xưng "I" như bản tiếng Việt xưng "tôi". Giữ nguyên tên riêng (GitHub, RSS, Markdown).
